# Некрополис

Браузерная tower defense в тёмном пиксельном фэнтези. Ты хранитель некрополиса: строй некромантские башни вдоль дороги и не дай рыцарям, священникам и осадным повозкам дойти до древнего склепа. 20 волн с боссами на 10-й и 20-й, примерно полчаса.

## Как играть

- Каждый забег идёт на новой карте и с новым составом волн, их задаёт сид (виден слева вверху). У части волн есть свойство: бронированная, быстрая, толпа, с лекарями, богатая. Первая волна стартует по кнопке, дальше — по таймеру паузы.
- Нажми на свободную клетку, затем на карточку башни внизу слева (или клавиши 1–7). Или наоборот: выбери башню и нажми на клетку. Особые клетки: курган (+1 к дальности), источник душ (+1 душа за убийство), проклятая земля (+25% урона, постройка дороже).
- Нажми на башню, чтобы качать её ветки — урон (Q), дальность (W), скорость (E), по пять ступеней — или продать (X). Когда в башню вложено шесть ступеней, выбирается один из трёх перков. В паузе башню можно перенести (M).
- Две соседние башни со всеми ветками на пятой ступени можно слить в гибрид (кнопка «Слить с соседом»): он атакует как первая башня, получает примесь второй, ветки до 8-й ступени и оба перка.
- Гримуар (✦ вверху или G) — общая прокачка за души: урон, дальность и скорость всех башен и урон каждого типа, действует и на построенные позже.
- После волн 5, 10 и 15 выбирается одна из трёх реликвий (клик или 1–3). Боссы — на 10-й и 20-й волне. После победы можно продолжить в бесконечном режиме.
- Разведка вверху слева: в паузе раскрывается превью следующих трёх волн (← →, I — свернуть). Во время волны там видно, сколько врагов осталось.
- Enter призывает волну раньше, Пробел — пауза, F — скорость ×2, Esc — меню. Прогресс сохраняется после каждой отбитой волны; открытия (новые башни и реликвии) копятся между забегами.

| Башня | Роль |
|---|---|
| Кости | дешёвый дальний урон по одиночкам, слаб против брони |
| Духи | замедляют врагов |
| Чума | ядовитое облако, бьёт толпу сквозь броню; главный урон в поздних волнах |
| Тьма | луч по самой живучей цели, вдвое сильнее по повозкам и боссам, пробивает защиту священников |
| Колокол | открывается: удар по площади вокруг себя с оглушением |
| Казарма | открывается: скелеты держат врагов на дороге |
| Алтарь крови | открывается: не стреляет, усиливает соседние башни |

## Запуск локально

Сборки не нужно: игра — статические файлы в `live/`.

```bash
python -m http.server 8930
# открыть http://127.0.0.1:8930/live/index.html
```

## Баланс и тесты

Все числа (башни, враги с ценой угрозы, генератор волн и свойства волн, Гримуар, реликвии, экономика, карта) лежат в `live/config.js`. Цели баланса для первого забега (открыто как у нового профиля): разумный бот без Гримуара и слияний побеждает в 30–60% забегов, бот с Гримуаром и слияниями — в 80% и больше, случайный — реже 5%; победа за 25–35 минут игры; без обороны — проигрыш на 2-й волне.

```bash
node --test tests/*.test.mjs   # все тесты, включая быструю проверку баланса на трёх сидах (tests/runs.mjs), ~40 с
node tools/check.mjs           # всё сразу: тесты, боты, браузер в окнах 1280 и 1920 (нужна переменная PLAYWRIGHT, см. AGENTS.md)
```

Инструменты баланса (тяжёлый счёт — через очередь: `node tools/slot.mjs --cpu <команда>`):

```bash
node tools/balance.mjs                       # боты idle, smart, grim, random на сидах 1..20, шаг 1/30, по ядрам: ~30 с
node tools/balance.mjs --seeds 100 --bots smart,grim --endless 5 --list
node tools/balance.mjs --open all --bots focus:bell,mono:plague
node tools/balance.mjs --set 'HP_MULT=(w)=>1+0.12*(w-1)'   # попробовать число, не правя конфиг
node tools/model.mjs                         # модель без симуляции на 1000 сидах: кривая запаса по волнам, ~3 с
node tools/model.mjs --seed 7                # таблица одного сида: угроза, души, оборона, запас по волнам
node tools/model.mjs --fit run.json          # подбор модели под прогон: node tools/balance.mjs --seeds 300 --json run.json
node tools/diag.mjs 7 grim                   # одна партия по волнам: прочность, души, урон по типам, что куплено
node tools/waves.mjs 200                     # генератор волн: размер, длительность и разброс HP волн
```

Как читать `balance.mjs`: на каждого бота — доля побед, среднее и разброс времени победы в минутах игры, прочность склепа у победителей и гистограмма волн, на которых проигрывают (`20×6` — шесть забегов упали на 20-й). Боты: `idle` ничего не делает; `smart` жадно покупает то, что даёт больше силы обороны на душу (постройку, ступень, перк), реликвию выбирает по оценке; `grim` — то же плюс Гримуар и слияния; `random` строит и качает наугад; `mono:<тип>` строит только этот тип, `focus:<тип>` ценит его вдвое. Под строкой бота — экономика: сколько душ заработано к 10-й и 20-й волне и сколько остаётся на руках к 20-й (близко к нулю — души в дефиците до конца); у `grim` ещё вложено в Гримуар и после какой волны первое слияние. Хорошая кривая — проигрыши разумного бота во второй половине забега.

Как читать `model.mjs`: запас волны = оборона, купленная на заработанные к ней души (с поправкой на карту), к типичной угрозе волны, минус один. Столбцы — медиана и 10%/90% по сидам, полоса — медиана. Запас должен плавно убывать к концу забега с провалами на боссах; «угроза к прошлой волне» меньше ×1 значит, что волна легче предыдущей. Модель грубая: долю проходимых забегов и форму кривой она даёт близко к ботам, а исход отдельного сида угадывает примерно в 70% случаев.

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` на каждый push в `main` гоняет тесты, собирает `site/` (`python3 tools/build_site.py`) и публикует его. Один раз включи в настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
