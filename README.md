# Некрополис

Браузерная tower defense в тёмном пиксельном фэнтези. Ты хранитель некрополиса: строй некромантские башни вдоль дороги и не дай рыцарям, священникам и осадным повозкам дойти до древнего склепа. 20 волн с боссами на 10-й и 20-й, примерно полчаса.

## Как играть

- Каждый забег идёт на новой карте и с новым составом волн, их задаёт сид (виден слева вверху). У части волн есть свойство: бронированная, быстрая, толпа, с лекарями, богатая.
- Нажми на свободную клетку, затем на карточку башни внизу слева (или клавиши 1–4). Или наоборот: выбери башню и нажми на клетку.
- Нажми на башню, чтобы качать её ветки — урон (Q), дальность (W), скорость (E), по пять ступеней — или продать (X). Когда в башню вложено шесть ступеней, выбирается один из трёх перков.
- Разведка вверху слева: в паузе между волнами раскрывается превью следующей волны (отряды, HP, броня, защита от магии, скорость, награда, свойство, босс), его можно листать на три волны вперёд (← →, I — свернуть). Во время волны там видно, сколько врагов осталось.
- Enter призывает волну раньше, Пробел ставит паузу, F переключает скорость ×2, Esc открывает меню.
- Прогресс сохраняется в браузере после каждой отбитой волны.

| Башня | Роль |
|---|---|
| Кости | дешёвый дальний урон по одиночкам, слаб против брони |
| Духи | замедляют врагов |
| Чума | ядовитое облако, бьёт толпу сквозь броню |
| Тьма | луч по самой живучей цели, вдвое сильнее по повозкам и боссам, пробивает защиту священников |

## Запуск локально

Сборки не нужно: игра — статические файлы в `live/`.

```bash
python -m http.server 8930
# открыть http://127.0.0.1:8930/live/index.html
```

## Баланс и тесты

Все числа (башни, враги с ценой угрозы, генератор волн и свойства волн, экономика, параметры генератора карты) лежат в `live/config.js`.

```bash
node --test tests/*.test.mjs # генераторы карты и волн, команды, детерминизм, сейв, боты
node tools/check.mjs        # всё сразу: тесты, боты, браузер в окнах 1280 и 1920 (нужна переменная PLAYWRIGHT, см. AGENTS.md)
node tools/balance.mjs 10   # сводка по сидам 1..10: бот без обороны, разумный бот, спам одной башни
node tools/waves.mjs 200    # генератор волн без симуляции: размер, длительность и разброс HP волн по 200 сидам
```

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` на каждый push в `main` гоняет тесты, собирает `site/` (`python3 tools/build_site.py`) и публикует его. Один раз включи в настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
